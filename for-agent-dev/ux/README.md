## 设计方向

**修仙 × 科技（Cultivation × Cyberpunk）**

- 玩家端 = 玄夜仙穹（深色）· 管理员端 = 琅嬛玉阁（浅色），双端世界观反差
- **八境色彩体系**：炼气灰 → 筑基青 → 结晶蓝 → 具灵青碧 → 悟道金 → 羽化朱霞 → 登仙紫 → 神魔曜金
- 技能难度 = Boss 等级（环形等级盘），勋章 = 篆书法印

## 使用约定

1. 设计改动需同时更新 `设计交付文档.md`，保持「文档即规格」
2. 原型使用模拟数据，与后端联调时按文档第 7 节映射华为云 API
3. 前端落地时，设计 Token 迁移至 `design-tokens.scss`，Element Plus 主题变量覆盖（玩家端主色鎏金 `#E7C87B`、管理端朱砂 `#C2452F`）
