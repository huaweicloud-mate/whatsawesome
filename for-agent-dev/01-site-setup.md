# Whats Awesome 项目规格

> 来源: 项目发起人需求 2026-08-13(2026-08-13 更新: 项目更名、数据库定 GaussDB、Agent 拆解定稿)
> 代码仓: https://github.com/huaweicloud-mate/whatsawesome (当前为空,全新项目)
> 技术基调: 所有能力优先选用华为云

## 1. 项目定位

**名称**: Whats Awesome(业务名 = 代码仓名)

**初衷**: 培养团队所有人的技能,AI 时代技能不能落后。

**一句话业务逻辑**: 所有人可以来"Whats Awesome"看到最新的技能发布、看到自己相关领域有哪些技能;可以亲手尝试每个技能,完成体验并亲手尝试后点亮该技能;每个人拥有专属主页,根据点亮的技能获得定制化勋章与 Title。

## 2. 核心对象(需解耦实现)

### 2.1 技能 Skill
- 来源: AI 大厂、云厂商(AWS / Google Cloud / 微软 Azure / 阿里云 / 腾讯云 / 华为云)、垂类场景成熟厂商(Vercel、GitHub 等)
- 提供应用开发过程中必要的能力与工具
- **Doc 属性**: 最新资讯、官方入口、开源地址、开源生态、Hello World 入门指导;最重要的是一段"提示词",供玩家复制后自己学习这项技能
- **标签属性**: 由谁发布、属于哪个技术领域(标签可配置)
- **难度属性(游戏化 Boss Lv)**:
  - 1~10 炼气期 | 11~20 筑基期 | 21~30 结晶期 | 31~40 具灵期 | 41~50 悟道期 | 51~60 羽化期 | 61~70 登仙期 | 71~100 神魔期
- **重要性属性**: 交给 AI 综合评估(未来必备技能给高分),总分 10 分

### 2.2 案例 Case
- 多个技能的组合;可 AI 生成,也可人工添加;场景化组合,供玩家探索与亲手实现
- 与技能一样具备: 标签、难度、重要性属性

### 2.3 玩家 Player
- 所有参与者都是"游戏闯关玩家",攻克技能或案例
- **勋章属性**: 能力与勋章匹配,如"亲手体验了 AWS 80% 以上能力 → AWS 通关达人"勋章 + Title
- **成长规则**: 炼气期 → 神魔期 的成长体系

## 3. 核心功能

1. **鉴权-用户面**: GitCode 账号登录(OAuth 2.0)
2. **鉴权-管理面**: 管理账号仅 2 人(发起人 + 秘书)
3. **管理面-技能管理**: 管理技能 Agent 当天最新生成/爬取的技能,决定哪些露出给玩家攻克
4. **资讯功能**: 技能 Agent 每天爬取全球最新技能趋势与发布;若关联某项技能,给超链接到技能详情页
5. **玩家闯关**: 玩家按技能 Doc 或自学完成点亮;
   - **闯关判定逻辑**: 由"裁判 Agent"负责,开发 MCP Server,参与者把自己的 Agent 连上,实现自动化技能点亮
   - 也可有其他判定逻辑(先商量)
6. **个人主页**: 极其炫酷;展示攻克了哪些技能、获得哪些勋章

## 4. 明确要求(含最终决策)

1. 项目名称: **Whats Awesome**
2. Agent 拆解(发起人定稿,6 个):
   - 1 个**项目经理 Agent**(规划协调、任务分派、验收组织)
   - 1 个**前端 Agent**(用户面 + 管理面 + 炫酷个人主页)
   - 1 个**后端 Agent**(全部领域 API、鉴权、点亮、勋章、存储)
   - 1 个**技能 Agent**(生成和管理最新技能、技能 Doc;资讯;生成案例)
   - 1 个**裁判 Agent**(判定某人是否实现了某个技能或案例,MCP Server)
   - 1 个**QA Agent**(测试整个系统)
3. 技术实现: 前端 Vue3 + Element Plus;后端华为云 FunctionGraph;**数据库定稿用 GaussDB(华为云)**;所有能力优先选用华为云
4. 合理迭代规划: 迭代一先做技能不管玩家;迭代二只做手工点亮(玩家上传截图/日志);后续迭代把闯关判定暴露为 MCP Server

## 5. 外部依赖确认

- GitCode OAuth 2.0: 已确认支持授权码模式(authorize → token → /api/v5/user),scope 可配置
- 华为云盘古大模型: ModelArts Studio 提供 API Key 认证 + OpenAI 兼容 V2 接口(/api/v2/chat/completions),可用于 AI 评估/生成
- 华为云 FunctionGraph: 官方支持一键部署 MCP Server(APIG + SSE),区域限制"西南-贵阳一 / 华北-北京四"
- 华为云 GaussDB: 关系型数据库(openGauss/MySQL 两种内核),支持 JSONB/JSON 列,用于落地对象化建模(见设计方案 §4)
